# Module Format

Not implemented yet.

Modules will define truths, constraints, maps, factions, characters, encounters, secrets,
story threads, and GM boundaries. The AI GM may perform the space between these anchors,
but may not overwrite protected canon or directly mutate authoritative state.

The module builder may later offer an AI-assisted content compiler that turns
natural-language author intent into draft structured resources. Those drafts must validate
against schema, references, gameplay constraints, safety requirements, and lore/style rules
before becoming a saved module. Authors should still be able to inspect and edit the
underlying structured files directly.
