# Asset Dropbox

Drop new raw assets here before integration.

This folder can hold:

- image, audio, video, model, and text exports
- zip bundles from ChatGPT or other tools
- companion manifests describing intended use
- rough drafts that still need review or naming cleanup

When possible, include a short manifest beside each batch:

```markdown
# Asset Batch Manifest

## Asset List

- `filename.png` - intended role or scene

## Intended Use

Reference art, UI asset, location art, character art, sound effect, music, map,
module illustration, or other project use.

## Notes

Source prompt, provenance, continuity constraints, revisions needed, or licensing notes.
```

After review, move accepted assets into a durable folder such as `assets/stylesheet/`
or a future category folder.
