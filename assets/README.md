# Assets

This folder is for source assets, raw creative exports, full-resolution art, audio,
reference images, drafts, and asset notes for Echoes of Tir Na Faileasan.

Use `_inbox/` as the asset dropbox for newly received files before they are reviewed,
renamed, optimized, or moved into a final project folder.

## Folders

- `_inbox/` - temporary dropoff area for incoming raw assets and zipped batches.
- `stylesheet/` - art direction, visual references, style guides, and UI style assets.

## Naming

Prefer lowercase, hyphen-separated filenames for durable assets:

```text
tir-na-faileasan-lantern-styleguide.jpg
chapter-01-location-map-draft.png
waypoint-lantern-icon-v01.png
```

Avoid vague names such as `final.png`, `new-image.jpg`, or `image-1.png` once an asset
is promoted out of `_inbox/`.
